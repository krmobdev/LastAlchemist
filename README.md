# Last Alchemist 🧪

A mobile-first alchemy management RPG built with Godot.

You are the last alchemist in a small laboratory. Take client orders, manage limited reagents, experiment with reactions, discover recipes, and grow the laboratory into a thriving business.

## Status
Early prototype — core project structure is being built.

## Planned systems
- Alchemy and reaction discovery
- Reagent inventory and economy
- Client orders and contracts
- Recipe book
- Laboratory upgrades
- Rare reactions and accidents
- Mobile-first UI

## Tech
- Godot 4.x
- GDScript
- Android target
- GitHub for source control and CI
